# DBF Manager - Pack and structure for DBF files you own

Pack and structure belong on one DBF you own, not on a pile of copies. Extra tables wait for their own title.

## Session Card

| Slice | What you do in DBF Manager | What remains |
|-------|----------------------------|--------------|
| Arrival | Open the DBF you own and name today's records desk | A titled pack session |
| Focus | Keep table pack and one structure edit in front | A short tool list |
| Check | Read the structure before you pack records you own | A confirmed DBF file |
| Handoff | Leave DBF Manager DBF tools on that records desk | A note for the next visit |

## How DBF Manager Sits

DBF Manager does not replace the backup folder you already keep for shop files. It sits beside that folder as named DBF tools for pack and structure edit on a file you own.

If two people share a PC, each keeps a DBF Manager records desk of their own. Extra tables wait for their own title instead of crowding the live pack.

A first visit should be one short structure edit, then the same DBF Manager table pack the next day. That is enough to see if the layout holds.

## Traffic Light

| Signal | On the DBF Manager records desk | What you do |
|--------|---------------------------------|-------------|
| Green | Named DBF, pack and structure on your file | Continue the same records desk |
| Amber | Two files mixed in one pack | Split the set before a large change |
| Red | No title, copies everywhere, structure unknown | Stop and name the records desk first |
| Clear | Handoff written, pack done on your table | Close DBF Manager and leave the file |

## Open Order

1. Open the last DBF Manager session on a DBF you own, not a new empty pack.
2. Read the structure edit and the last handoff.
3. Finish one visible pack or structure change inside DBF Manager DBF tools.
4. Write what changed on your own records, then close with fewer loose copies than you found.
5. If the records desk feels crowded, drop anything that belongs to a different DBF.
6. Leave table pack on the same named DBF Manager records desk.

## After a Week

A week in DBF Manager is not more open copies. It is the same table pack, a shorter structure list, and a note that still makes sense on Monday. If every DBF is packed at once, nothing stands out.

Take finished packs off the live set so the next visit starts on the file that is still open.

Other programs stay where they are. DBF Manager only keeps the path back: file name, pack, structure edit, handoff.
Leave the records desk quieter than the pack you opened.

## Sign-off

- [ ] The DBF Manager file name is short enough to scan
- [ ] Only DBF files you own are on the records desk
- [ ] A second person can read the last structure note
- [ ] The last DBF Manager session still opens after a restart
- [ ] Finished packs are off the live set
- [ ] Structure edit still matches DBF Manager DBF tools
- [ ] The records handoff still names the owned table

## Field Note

DBF Manager is easier to trust when the records desk stays smaller than the folder of loose copies around it. Name the file, keep table pack and structure edit on records you own, finish one visible step, and write what changed.

The same loop fits a shop file, a clerk packet, or a shared computer. Open the last DBF Manager records desk and continue. Do not rebuild the pack layout from scratch.
